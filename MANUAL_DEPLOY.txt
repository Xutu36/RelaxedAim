===============================================
RelaxedAim ConsoleDebug-v1 - 手动部署说明
===============================================

【重要】由于系统限制,无法自动复制到游戏目录
       请按以下步骤手动操作

步骤1: 确认文件位置
-------------------
源文件 (刚才编译的):
  D:\PZMod\RelaxedAim\java\build\libs\RelaxedAim.jar

目标文件 (游戏使用的):
  C:\Users\Administrator\Zomboid\mods\RelaxedAim\42\media\java\client\RelaxedAim.jar

步骤2: 手动复制文件
-------------------
方法A - 使用资源管理器:
  1. 打开文件夹: D:\PZMod\RelaxedAim\java\build\libs\
  2. 右键点击 RelaxedAim.jar → 复制
  3. 打开文件夹: C:\Users\Administrator\Zomboid\mods\RelaxedAim\42\media\java\client\
  4. 右键 → 粘贴, 选择"替换目标中的文件"
  5. 确认修改时间已更新

方法B - 使用PowerShell (管理员权限):
  1. 以管理员身份运行PowerShell
  2. 执行以下命令:

     Copy-Item -Path 'D:\PZMod\RelaxedAim\java\build\libs\RelaxedAim.jar' `
       -Destination 'C:\Users\Administrator\Zomboid\mods\RelaxedAim\42\media\java\client\RelaxedAim.jar' `
       -Force

  3. 确认没有报错

步骤3: 验证文件已更新
---------------------
1. 查看目标文件的修改时间:
   - 右键 RelaxedAim.jar → 属性
   - 确认"修改时间"是刚才复制的时间

2. 文件大小应该约为 8KB (8,092 字节)

步骤4: 测试游戏
--------------
1. 完全关闭游戏 (如果正在运行)
2. 重新启动 Project Zomboid
3. 在主菜单界面,查看左上角

   旧版本显示: "RelaxedAim loaded"
   新版本显示: "RelaxedAim ConsoleDebug-v1"

4. 如果看到 "ConsoleDebug-v1",说明部署成功!

故障排查
--------
问题: 复制时提示"拒绝访问"或"需要管理员权限"
解决: 
  - 使用PowerShell管理员模式
  - 或暂时关闭杀毒软件实时保护
  - 或修改目标文件夹权限

问题: 游戏仍然显示旧版本
解决:
  1. 确认文件修改时间已更新
  2. 完全关闭游戏后重新启动
  3. 检查是否启用了多个版本的模组
  4. 尝试清除Steam缓存: Steam → 右键游戏 → 属性 → 本地文件 → 验证完整性

问题: 游戏启动时崩溃
解决:
  1. 暂时禁用其他所有模组,只保留 ZombieBuddy + RelaxedAim
  2. 检查 console.txt 中的错误信息
  3. 确认 ZombieBuddy 版本兼容

联系支持
--------
如果以上步骤都无法解决问题,请提供:
1. 你的操作系统版本
2. Project Zomboid 版本
3. console.txt 文件内容
4. 截图显示左上角显示的文字
